# POG予測システム

競馬のPOG（ペーパーオーナーゲーム）で有望な2歳馬をランク付けするシステム。
デビュー前に入手可能な情報のみを使い、ヒューリスティックスコアでTOP10を予測する。

## スコアリング

血統スコア・性別・人的要素をベースに、ボーナス/ペナルティを加減算する。
重みは8年分LOO-CVランダムサーチ（TOP10最適化）で最適化し、`data/config/weights.json` で管理。

| 要素 | 配点 | 説明 |
|------|------|------|
| 性別 | ±7.7pt | 牡馬に加算、牝馬に減算 |
| 父EI | 最大22.5pt | 種牡馬の産駒EI（99%ile正規化×100×0.225） |
| 初年度種牡馬 | log(賞金)×2.0 | 産駒EI未知の新種牡馬を自身の賞金で補正 |
| 早生まれ | +8.5pt | 1〜4月生まれ |
| 調教師 | (スコア-50)×0.34 | 実績スコア（50基準、最大+17pt） |
| 馬主 | (スコア-50)×0.34 | 実績スコア（50基準、最大+17pt） |
| 両親若齢 | +3.3pt | 父母とも13歳以下 |
| 母馬繁殖入り年齢 | -6.9〜+1.1pt | 若い繁殖入り（=良血）ほど加算 |
| 母父EI | 最大1.0pt | 母父馬の産駒EI（99%ile正規化×100×0.01） |
| 産駒番号 | -0.7 / +0.3pt | 初仔ペナルティ、2〜4番仔にボーナス |
| 母-母父年齢差 | +0.2pt | 母と母父の年齢差が小さい |
| 母馬獲得賞金 | 0pt※ | 現在重み0 |
| セリ価格 | 0pt※ | 現在重み0 |
| 生産牧場 | 0pt※ | 現在重み0 |

※ 特徴量として保持しているが、TOP10最適化で重み0に収束

EIデータは年度別リーディングを参照し、バックテスト時の未来データリークを防止する
（生年Yの馬 → Y+1年のリーディングを使用）。

## ファイル構成

```
run.py                          エントリーポイント
backtest.py                     バックテスト（精度検証）
backtest_ensemble.py            アンサンブルバックテスト（H+LightGBM）
grid_search.py                  LOO-CVグリッドサーチ（重み最適化）
fetch_dam_prizes.py             母馬獲得賞金の一括取得

scripts/
  fetch_leading.py              種牡馬/BMSリーディング取得（年度別）
  fetch_all_features.py         生年月日・セリ価格・産駒番号の取得

src/
  scraper.py    netkeiba.comスクレイピング（馬一覧 + 親ID/生年）
  features.py   特徴量生成（年度別EI・母馬賞金・調教師・牧場等）
  model.py      ヒューリスティックスコア算出（重みはweights.jsonから読込）
  predictor.py  収集→予測パイプライン

data/
  horses_YYYY.csv               馬一覧（親ID・生年含む）
  sire_leading_YYYY.json        種牡馬リーディング（年度別）
  bms_leading_YYYY.json         母父馬リーディング（年度別）
  dam_prizes.json               母馬獲得賞金
  dam_foals.json                母馬の産駒リスト（産駒番号算出用）
  birth_dates_YYYY.json         生年月日キャッシュ
  extra_features_YYYY.json      セリ価格・産駒番号キャッシュ
  config/
    weights.json                スコアリング重みパラメータ
    elite_trainers.json         エリート調教師スコア
    elite_owners.json           エリート馬主スコア
    elite_breeders.json         エリート生産牧場スコア
```

## 使い方

```bash
pip install -r requirements.txt

# 全自動（データ収集→予測）
python run.py --year 2024

# データ収集のみ
python run.py --mode collect --year 2024

# 予測のみ（収集済みデータ使用）
python run.py --mode predict --year 2024 --top-n 10

# リーディングデータの取得（年度別）
python scripts/fetch_leading.py 2024
python scripts/fetch_leading.py --years 2016 2017 2018 2019 2020 2021 2022

# 追加特徴量の取得（生年月日・セリ価格・産駒番号）
python scripts/fetch_all_features.py 2024

# 母馬獲得賞金の取得
python fetch_dam_prizes.py --year 2024

# バックテスト
python backtest.py 2021
python backtest_ensemble.py --all

# グリッドサーチ（重み最適化）
python grid_search.py                    # バランス型（Spearman+TOP+賞金倍率）
python grid_search.py --objective top10  # TOP10特化型
```

## バックテスト結果（2015〜2022年産駒）

各年度の産駒についてデビュー前情報のみで予測し、実際の獲得賞金ランキングと比較した結果。

### ヒューリスティックモデル（TOP10最適化）

| 年度 | Spearman | TOP10一致 | TOP30一致 | TOP50一致 | 賞金倍率 |
|------|----------|-----------|-----------|-----------|----------|
| 2015 | 0.1754 | 4/10 | 5/30 | 7/50 | 8.63x |
| 2016 | 0.1535 | 2/10 | 6/30 | 7/50 | 8.39x |
| 2017 | 0.1258 | 2/10 | 5/30 | 5/50 | 8.85x |
| 2018 | 0.1539 | 0/10 | 2/30 | 4/50 | 4.40x |
| 2019 | 0.1327 | 2/10 | 4/30 | 5/50 | 11.46x |
| 2020 | 0.1070 | 1/10 | 3/30 | 5/50 | 5.76x |
| 2021 | 0.1752 | 1/10 | 6/30 | 7/50 | 7.08x |
| 2022 | 0.1569 | 2/10 | 3/30 | 4/50 | 10.40x |
| **平均** | **0.1476** | **1.75/10** | **4.25/30** | **5.5/50** | **8.12x** |

### アンサンブル（ヒューリスティック50% + LightGBM 50%）

| 年度 | Spearman | TOP10一致 | TOP30一致 | TOP50一致 | 賞金倍率 |
|------|----------|-----------|-----------|-----------|----------|
| 2015 | 0.1869 | 2/10 | 5/30 | 6/50 | 8.16x |
| 2016 | 0.1682 | 1/10 | 4/30 | 6/50 | 7.00x |
| 2017 | 0.1394 | 0/10 | 4/30 | 6/50 | 8.07x |
| 2018 | 0.1726 | 0/10 | 2/30 | 5/50 | 4.10x |
| 2019 | 0.1572 | 2/10 | 3/30 | 4/50 | 9.92x |
| 2020 | 0.1198 | 1/10 | 3/30 | 6/50 | 5.38x |
| 2021 | 0.1848 | 1/10 | 4/30 | 6/50 | 5.76x |
| 2022 | 0.1543 | 0/10 | 2/30 | 6/50 | 4.31x |
| **平均** | **0.1604** | **0.88/10** | **3.38/30** | **5.63/50** | **6.59x** |

- **Spearman**: 予測スコアと実賞金のスピアマン順位相関（全年度で有意 p<0.001）
- **TOP N一致**: 予測TOP Nと実績TOP Nの重複数
- **賞金倍率**: 予測TOP30の平均賞金 / 全体平均賞金（高いほど上位馬を選別できている）

ヒューリスティックモデルはTOP10的中に特化しており、8年間で合計14頭（年平均1.75頭）を的中。
アンサンブルはSpearman相関が高く全体的な順位予測に優れるが、TOP10の精度はヒューリスティック単体が上回る。
