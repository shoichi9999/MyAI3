# POG予測システム

競馬のPOG（ペーパーオーナーゲーム）で有望な2歳馬をランク付けするシステム。
デビュー前に入手可能な情報のみを使い、ヒューリスティックスコアで**ダービー・オークスの好走馬**を予測する。
LightGBMとのアンサンブル予測にも対応。

## コンセプト

- **予測対象**: 日本ダービーTOP5（牡馬）＋ オークスTOP5（牝馬）
- **選出方法**: 牡馬TOP5・牝馬TOP5をそれぞれ選出
- **評価方法**: 選出した5頭がダービー/オークスTOP5に何頭入っているか＋1着馬の予測順位
- **最適化目標**: 1着馬のTOP5入りを最優先（ダービー8年中6年、オークス8年中3年で達成）
- **最適化手法**: 8年分（2015〜2022年産）のLOO-CVでDE探索（38パラメータ）
- **アンサンブル**: ヒューリスティックスコアとLightGBM予測をalphaブレンドで統合

## スコアリング

### ヒューリスティックモデル

血統スコア・人的要素をベースに、ボーナス/ペナルティを加減算する。
重みはダービー用 `data/config/weights.json`、オークス用 `data/config/weights_oaks.json` で管理し、
それぞれ独立に最適化済み（38パラメータ）。

#### 主要特徴量

| カテゴリ | 特徴量 | 説明 |
|---------|--------|------|
| 血統（父） | 父EI、父産駒数、父産駒賞金、父勝率、父ランク | 種牡馬リーディングデータ（年度別） |
| 血統（父） | 父EIトレンド | 前年比EI変化（上昇トレンド = 加点） |
| 血統（父） | 父クラシック率、父クラシック輩出数 | ダービー+オークスTOP5輩出実績 |
| 血統（父） | 初年度種牡馬ボーナス | 初年度種牡馬内の相対スコア |
| 血統（母父） | 母父EI、母父産駒数、母父勝率、母父ランク、母父産駒賞金 | BMSリーディングデータ |
| 血統（母） | 母馬獲得賞金、母馬繁殖入り年齢、輸入繁殖牝馬 | 母馬の実績・背景 |
| 血統（母） | 母馬産駒品質、母馬総産駒数 | 兄姉クラシック率、適正産駒数 |
| 交互作用 | 父EI×母賞金、母父EI×母賞金 | 良血×良血のシナジー |
| 人的要素 | 調教師、馬主、生産牧場 | エリートスコア（50基準） |
| 人的要素 | 調教師×生産者、馬主×調教師 | コンボボーナス |
| その他 | 早生まれ、産駒番号、セリ価格、兄姉クラシック実績 | 時点制約済み |

#### データリーク防止

- EI・勝率・ランク・産駒数 → 生年Y+1年のリーディングを使用（POGドラフト時点で入手可能）
- 兄姉クラシック・種牡馬クラシック輩出 → birth_year-2以前の結果のみ
- 父EIトレンド → 生年Y+1年と生年Y年のEI差（ドラフト時点で入手可能）

### LightGBMモデル（実験的）

`src/ml_model.py` にて特徴量を使った2値分類モデルを実装。
Leave-One-Year-Out CVで学習し、ヒューリスティックスコアをスタッキング特徴量として利用可能。

- **アンサンブル**: `alpha`パラメータでブレンド比率を調整（0=ML only、1=heuristic only）
- **現状**: alpha=1.0（ヒューリスティックのみ）が最良。MLモデルは追加データ/特徴量で改善の余地あり

## ファイル構成

```
run.py                          エントリーポイント
backtest.py                     バックテスト（ダービー/オークスTOP5予測精度検証）
backtest_ensemble.py            アンサンブルバックテスト（ヒューリスティック×LightGBM）
grid_search.py                  DE最適化（重みパラメータ探索、TOP5目的関数）
tune_new_params.py              新パラメータ高速チューニング
fetch_dam_prizes.py             母馬獲得賞金の一括取得
fetch_sire_prizes.py            種牡馬賞金の取得
fetch_all_years.py              全年度データの一括取得
run_dam_pipeline.py             母馬データパイプライン

scripts/
  fetch_leading.py              種牡馬/BMSリーディング取得（年度別）
  fetch_all_features.py         生年月日・セリ価格・産駒番号の取得

src/
  scraper.py    netkeiba.comスクレイピング（馬一覧 + 親ID/生年）
  features.py   特徴量生成（43特徴量: EI・勝率・ランク・産駒数・母馬賞金・人的要素・交互作用等）
  model.py      ヒューリスティックスコア算出（重みはweights.jsonから読込、38パラメータ）
  ml_model.py   LightGBM予測モデル（LOYO-CV + スタッキング + アンサンブル）
  predictor.py  収集→予測パイプライン

data/
  horses_YYYY.csv               馬一覧（親ID・生年含む）
  classic_results.json           ダービー/オークスTOP5結果データ
  sire_leading_YYYY.json        種牡馬リーディング（年度別、rank/ei/win_rate/runners等）
  bms_leading_YYYY.json         母父馬リーディング（年度別）
  dam_prizes.json               母馬獲得賞金
  dam_foals.json                母馬の産駒リスト（産駒番号算出用）
  sire_prizes.json              種牡馬の競走成績賞金
  birth_dates_YYYY.json         生年月日キャッシュ
  extra_features_YYYY.json      セリ価格・産駒番号キャッシュ
  foreign_birth_years.json      外国産馬メタデータ
  config/
    weights.json                ダービー用スコアリング重み（最適化済み、38パラメータ）
    weights_oaks.json           オークス用スコアリング重み（最適化済み、38パラメータ）
    elite_trainers.json         エリート調教師スコア
    elite_owners.json           エリート馬主スコア
    elite_breeders.json         エリート生産牧場スコア
```

## 使い方

```bash
pip install -r requirements.txt
pip install lightgbm  # アンサンブル機能を使う場合

# 全自動（データ収集→予測）
python run.py --year 2024
python run.py --year 2024 --race oaks   # オークス予測

# データ収集のみ
python run.py --mode collect --year 2024

# 予測のみ（収集済みデータ使用）
python run.py --mode predict --year 2024 --top-n 5
python run.py --mode predict --year 2024 --top-n 5 --race oaks

# リーディングデータの取得（年度別）
python scripts/fetch_leading.py 2024

# 追加特徴量の取得（生年月日・セリ価格・産駒番号）
python scripts/fetch_all_features.py 2024

# 母馬獲得賞金の取得
python fetch_dam_prizes.py --year 2024

# バックテスト（ヒューリスティック）
python backtest.py 2021
python backtest.py --all
python backtest.py --race oaks --all   # オークス

# アンサンブルバックテスト
python backtest_ensemble.py 2021
python backtest_ensemble.py --all --sweep   # alpha最適値を探索

# 重み最適化（Differential Evolution）
python grid_search.py                       # ダービー
python grid_search.py --race oaks           # オークス
python tune_new_params.py                   # 新パラメータのみ高速チューニング
python tune_new_params.py --race oaks
```
