# POG予測システム

競馬のPOG（ペーパーオーナーゲーム）で有望な2歳馬をランク付けするシステム。
デビュー前に入手可能な情報のみを使い、ヒューリスティックスコアで**ダービー・オークスの好走馬**を予測する。

## コンセプト

- **予測対象**: 日本ダービーTOP5 + オークスTOP5（計10頭/年）
- **使用情報**: デビュー前に入手可能な血統・セリ・人的データのみ
- **評価方法**: 牡馬の予測TOP10からダービーTOP5を、牝馬の予測TOP10からオークスTOP5を何頭当てられるか
- **最適化**: 8年分（2015〜2022年産）のLOO-CVでscipy Differential Evolutionによりパラメータ探索

## スコアリング

血統スコア・性別・人的要素をベースに、ボーナス/ペナルティを加減算する。
重みは`data/config/weights.json`で管理。

| 要素 | 配点 | 説明 |
|------|------|------|
| 早生まれ | +19.9pt | 1〜4月生まれ |
| セリ価格 | 最大17.6pt | セリ価格（正規化後×重み） |
| 初年度種牡馬 | 最大14.4pt | 年内正規化（同年の初年度種牡馬内での相対順位×重み） |
| 母馬繁殖入り年齢 | -3.7〜+9.2pt | 若い繁殖入り（=良血）ほど加算 |
| 産駒番号 | -1.0 / +8.3pt | 初仔ペナルティ、2〜4番仔にボーナス |
| 母父EI | 最大3.6pt | 母父馬の産駒EI（99%ile正規化×100×0.036） |
| 両親若齢 | +3.3pt | 父母とも13歳以下 |
| 母-母父年齢差 | +1.5pt | 母と母父の年齢差が小さい |
| 性別 | ±0.7pt | 牡馬に加算、牝馬に減算 |
| 調教師 | (スコア-50)×0.6 | 実績スコア（50基準、最大+30pt） |
| 馬主 | (スコア-50)×0.6 | 実績スコア（50基準、最大+30pt） |
| 生産牧場 | (スコア-50)×0.6 | 実績スコア（50基準、最大+30pt） |
| 母馬獲得賞金 | 最大16.1pt | 対数正規化 |
| 父EI | 0pt | 重み0に収束（母父EI・初年度種牡馬で代替） |
| 種牡馬高齢 | -0.2pt/年 | 16歳超で年齢に応じた減点 |

EIデータは年度別リーディングを参照し、バックテスト時の未来データリークを防止する
（生年Yの馬 → Y+1年のリーディングを使用）。

## ファイル構成

```
run.py                          エントリーポイント
backtest.py                     バックテスト（ダービー/オークスTOP5予測精度検証）
grid_search.py                  DE最適化（重みパラメータ探索）
fetch_dam_prizes.py             母馬獲得賞金の一括取得

scripts/
  fetch_leading.py              種牡馬/BMSリーディング取得（年度別）
  fetch_all_features.py         生年月日・セリ価格・産駒番号の取得

src/
  scraper.py    netkeiba.comスクレイピング（馬一覧 + 親ID/生年）
  features.py   特徴量生成（年度別EI・母馬賞金・調教師・牧場等）
  model.py      ヒューリスティックスコア算出（重みはweights.jsonから読込）
  predictor.py  収集→予測パイプライン

data/
  horses_YYYY.csv               馬一覧（親ID・生年含む）
  classic_results.json           ダービー/オークスTOP5結果データ
  sire_leading_YYYY.json        種牡馬リーディング（年度別）
  bms_leading_YYYY.json         母父馬リーディング（年度別）
  dam_prizes.json               母馬獲得賞金
  dam_foals.json                母馬の産駒リスト（産駒番号算出用）
  birth_dates_YYYY.json         生年月日キャッシュ
  extra_features_YYYY.json      セリ価格・産駒番号キャッシュ
  config/
    weights.json                スコアリング重みパラメータ
    elite_trainers.json         エリート調教師スコア
    elite_owners.json           エリート馬主スコア
    elite_breeders.json         エリート生産牧場スコア
```

## 使い方

```bash
pip install -r requirements.txt

# 全自動（データ収集→予測）
python run.py --year 2024

# データ収集のみ
python run.py --mode collect --year 2024

# 予測のみ（収集済みデータ使用）
python run.py --mode predict --year 2024 --top-n 10

# リーディングデータの取得（年度別）
python scripts/fetch_leading.py 2024

# 追加特徴量の取得（生年月日・セリ価格・産駒番号）
python scripts/fetch_all_features.py 2024

# 母馬獲得賞金の取得
python fetch_dam_prizes.py --year 2024

# バックテスト
python backtest.py 2021
python backtest.py --all

# 重み最適化（Differential Evolution）
python grid_search.py --objective top10
```
