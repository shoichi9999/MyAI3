# POG予測システム

競馬のPOG（ペーパーオーナーゲーム）で有望な2歳馬をランク付けするシステム。
デビュー前に入手可能な情報のみを使い、ヒューリスティックスコアで**ダービー・オークスの好走馬**を予測する。
LightGBMとのアンサンブル予測にも対応。

## コンセプト

- **予測対象**: 日本ダービーTOP5 + オークスTOP5（計10頭/年）
- **選出方法**: 性別問わず予測スコアTOP10を選出
- **評価方法**: 選出した10頭がダービーTOP5・オークスTOP5に何頭入っているか
- **最適化**: 8年分（2015〜2022年産）のLOO-CVでパラメータ探索（36パラメータ）
- **アンサンブル**: ヒューリスティックスコアとLightGBM予測をalphaブレンドで統合

## スコアリング

### ヒューリスティックモデル

血統スコア・人的要素をベースに、ボーナス/ペナルティを加減算する。
重みは`data/config/weights.json`で管理し、最適化済み（36パラメータ）。

| 要素 | 配点 | 説明 |
|------|------|------|
| 初年度種牡馬 | 最大70.3pt | 初年度種牡馬内の種牡馬賞金を正規化してスコア付け |
| 早生まれ | +43.9pt | 1〜4月生まれ |
| 輸入繁殖牝馬 | +43.6pt | 海外産の母馬（dam_prize不明でも良血の可能性） |
| 父EI | 最大29.5pt | 父馬の産駒EI（99%ile正規化×100×0.295） |
| 母馬獲得賞金 | 最大26.2pt | 対数正規化（99%ile）×100×0.262 |
| セリ価格 | 最大23.6pt | セリ価格（正規化後×重み） |
| 種牡馬ランクスコア | 最大21.8pt | リーディング順位を逆転スコア化（0.218×100） |
| 母馬繁殖入り年齢 | -16.3〜+17.0pt | 若い繁殖入り（=良血）ほど加算 |
| 母父産駒数 | 最大14.4pt | 母父の産駒出走頭数（対数正規化×100×0.144） |
| 母馬総産駒数 | +13.2pt | 3〜6頭の適正範囲にボーナス |
| 母父勝率 | 最大12.7pt | 母父馬の産駒勝率（0.127×100） |
| 種牡馬産駒数 | 最大11.2pt | 産駒出走頭数（対数正規化×100×0.112） |
| 産駒番号 | +8.9pt / -0.7pt | 2〜4番仔にボーナス、初仔にペナルティ |
| 母-母父年齢差 | +5.7pt | 母と母父の年齢差が小さいほど加算 |
| 種牡馬産駒総賞金 | 最大5.4pt | 産駒総賞金（対数正規化×100×0.054） |
| 両親若齢 | +4.4pt | 両親が若齢の場合にボーナス |
| 母馬産駒品質 | 最大2.3pt | 兄姉のクラシックTOP5率（時点制約済み） |
| 性別 | ±1.7pt | 牡馬に加算、牝馬に減算（低めに設定 → 牝馬も公平に評価） |
| 母父EI | 最大1.7pt | 母父馬の産駒EI（99%ile正規化×100×0.017） |
| 種牡馬クラシック輩出 | ×1.1pt | クラシックTOP5輩出数（時点制約済み） |
| 調教師 | (スコア-50)×1.77 | 実績スコア（50基準） |
| 馬主 | (スコア-50)×1.23 | 実績スコア（50基準） |
| 父EI×母賞金 | ×0.46 | 良血父×良血母のシナジー（99%ile正規化） |
| 調教師×生産者コンボ | ×0.061 | 基準値超過分に重み |
| 生産牧場 | (スコア-50)×0.04 | 実績スコア（50基準） |

EI・勝率・ランク・産駒数データは年度別リーディングを参照し、バックテスト時の未来データリークを防止する
（生年Yの馬 → Y+1年のリーディングを使用）。
兄姉クラシック実績・種牡馬クラシック輩出数もPOGドラフト時点（birth_year-2以前）で制約。

### LightGBMモデル（実験的）

`src/ml_model.py` にて特徴量を使った2値分類モデルを実装。
Leave-One-Year-Out CVで学習し、ヒューリスティックスコアをスタッキング特徴量として利用可能。

- **アンサンブル**: `alpha`パラメータでブレンド比率を調整（0=ML only、1=heuristic only）
- **現状**: alpha=1.0（ヒューリスティックのみ）が最良。MLモデルは追加データ/特徴量で改善の余地あり

## ファイル構成

```
run.py                          エントリーポイント
backtest.py                     バックテスト（ダービー/オークスTOP5予測精度検証）
backtest_ensemble.py            アンサンブルバックテスト（ヒューリスティック×LightGBM）
grid_search.py                  DE最適化（重みパラメータ探索、classic/top10目的関数）
fetch_dam_prizes.py             母馬獲得賞金の一括取得
fetch_sire_prizes.py            種牡馬賞金の取得
fetch_all_years.py              全年度データの一括取得
run_dam_pipeline.py             母馬データパイプライン

scripts/
  fetch_leading.py              種牡馬/BMSリーディング取得（年度別）
  fetch_all_features.py         生年月日・セリ価格・産駒番号の取得

src/
  scraper.py    netkeiba.comスクレイピング（馬一覧 + 親ID/生年）
  features.py   特徴量生成（40特徴量: EI・勝率・ランク・産駒数・母馬賞金・人的要素・交互作用等）
  model.py      ヒューリスティックスコア算出（重みはweights.jsonから読込、36パラメータ）
  ml_model.py   LightGBM予測モデル（LOYO-CV + スタッキング + アンサンブル）
  predictor.py  収集→予測パイプライン

data/
  horses_YYYY.csv               馬一覧（親ID・生年含む）
  classic_results.json           ダービー/オークスTOP5結果データ
  sire_leading_YYYY.json        種牡馬リーディング（年度別、rank/ei/win_rate/runners等）
  bms_leading_YYYY.json         母父馬リーディング（年度別）
  dam_prizes.json               母馬獲得賞金
  dam_foals.json                母馬の産駒リスト（産駒番号算出用）
  sire_prizes.json              種牡馬の競走成績賞金
  birth_dates_YYYY.json         生年月日キャッシュ
  extra_features_YYYY.json      セリ価格・産駒番号キャッシュ
  foreign_birth_years.json      外国産馬メタデータ
  config/
    weights.json                スコアリング重みパラメータ（最適化済み、36パラメータ）
    elite_trainers.json         エリート調教師スコア
    elite_owners.json           エリート馬主スコア
    elite_breeders.json         エリート生産牧場スコア
```

## 使い方

```bash
pip install -r requirements.txt
pip install lightgbm  # アンサンブル機能を使う場合

# 全自動（データ収集→予測）
python run.py --year 2024

# データ収集のみ
python run.py --mode collect --year 2024

# 予測のみ（収集済みデータ使用）
python run.py --mode predict --year 2024 --top-n 10

# リーディングデータの取得（年度別）
python scripts/fetch_leading.py 2024

# 追加特徴量の取得（生年月日・セリ価格・産駒番号）
python scripts/fetch_all_features.py 2024

# 母馬獲得賞金の取得
python fetch_dam_prizes.py --year 2024

# バックテスト（ヒューリスティック）
python backtest.py 2021
python backtest.py --all

# アンサンブルバックテスト
python backtest_ensemble.py 2021
python backtest_ensemble.py 2021 --alpha 0.3
python backtest_ensemble.py --all --sweep   # alpha最適値を探索

# 重み最適化（Differential Evolution）
python grid_search.py --objective top10
python grid_search.py --objective classic   # ダービー/オークスTOP5ベースの評価
```
